# 放置ペト 企画メモ

正本は Notion の「放置ペト」ページ。ここは開発用の要約。

## コンセプト

- 細かめのドット絵のペットが、モニターの四隅やタスクバーの上を歩き回る（場所は設定できる）
- いっぱい構うと、猫や犬など自分の育てたいペットの見た目になっていく
- 放置しすぎたり排泄物を片づけなかったりすると、きらい度が上がり、だんだんグロくなる

## ゲームループ

```
【PC系】PC作業・ゲーム同伴 → 時間で自動的に「ごはん系」
【PC以外】家事・運動・外出など → 自分でチェックして「みず系」
【散歩】長時間作業するとペトが散歩を要求 → PCから離れて休憩した時間が散歩になる
【撫で】マウスで実際にペトを撫でる
  ↓
世話に使う → 懐き度↑・姿が決まる
何もしない → 空腹・うんち放置 → きらい度↑ → グロくなる
```

| 種類 | 内容 | 入り方 | 手に入るもの |
| --- | --- | --- | --- |
| PC系 | PC作業、ゲーム同伴 | 時間で自動 | ごはん系 |
| PC以外 | 家事、運動、外出、勉強など | 自分でチェック | みず系 |
| 散歩 | ペトの要求に応えてPCから離れて休憩 | 離席時間で自動 | 懐き↑、犬寄りの姿に |
| 撫で | マウスでペトを撫でる | 実際の操作 | 懐き↑、猫寄りの姿に |

- うんちの掃除はアイテム不要でクリックだけ
- 散歩（案）：5分未満は数えない、上限は30〜60分程度
- 撫で（案）：短時間に撫でる効果は徐々に下げる（自動操作ツール対策）
- 将来：スマホ連携で、実際の散歩にペトを連れていける

## 見た目の2軸

- 種類の軸：散歩が多いと犬寄り、撫でが多いと猫寄り、その中間も出る
- 状態の軸：懐き度ときらい度の差で、かわいい〜グロが決まる

## 自動判定

1. 前面アプリの実行ファイルが Steam・Epic・Battle.net などのライブラリ内ならゲーム
2. ブラウザや動画プレイヤー以外で画面いっぱいのウィンドウならゲームの可能性が高い
3. ユーザーが「これはゲーム」「これはゲームじゃない」を登録できる

- ゲーム以外のアプリが前面にあり、操作が続いていれば PC 作業
- 見ているのはアプリ名と場所だけで、外部には送らない

## 技術メモ

- 透明・最前面・クリック素通り：Windows API（UniWindowController を試す）
- 自前実装なら Player Settings の「Use DXGI flip model swapchain」をオフ
- ペットの大きさの小さなウィンドウ自体を動かす（軽い・複数モニター対応しやすい）
- `Application.targetFrameRate` を 15〜30 に下げる
- 排他フルスクリーンのゲームの上には重ねられない
- 操作が止まった時間：GetLastInputInfo
- 前面アプリ：GetForegroundWindow → プロセスの実行ファイルのパス
- ドット絵：Pixel Perfect Camera
